# SORAVYN — Analytics, Metrics and Brand Memory Feedback Loop

## 1. Overview

The analytics module closes SORAVYN Studio's cybernetic loop by turning real distribution data into continuous strategic learning for the agency.
The metrics collected on each published post or video (reach, clicks, likes, shares, comments, conversions and ROI) are aggregated and injected into an **automatic AI feedback loop** that updates the editorial rules and the persona affinity of the Brand Memory (`brand_profiles`).

---

## 2. Architecture and components

### 2.1 Data model (`packages/db/src/schema/marketing_analytics.ts`)
- **`content_performance_metrics`**:
  - Engagement and financial metrics per slot or publication (`impressions`, `views`, `clicks`, `likes`, `shares`, `comments`, `conversions`, `spend_cents`, `revenue_cents`).
  - Automatic computation of the engagement rate (`engagement_rate` %) and of net return on investment (`roi_percent` %).
  - Time indexing (`company_id`, `calendar_item_id`, `channel`, `recorded_at`).
- **`strategic_insights`**:
  - Tactical recommendations generated by the AI (`category`: `channel`, `persona`, `format`, `angle`).
  - Factual finding (`observation`), recommended action (`recommendation`), impact level (`high`, `medium`, `low`) and confidence index.
  - Synchronization state with the Brand Memory (`applied_to_brand_memory`).

### 2.2 Analytics engine and learning loop (`server/src/services/marketing-analytics.ts`)
- **Batch ingestion and safe computation**: performance is recorded in batches with strict Zod validation.
- **Consolidated summary (`getAnalyticsOverview`)**: instant computation of click and conversion totals, average engagement rate, the over-performing channel and a granular breakdown.
- **Autonomous feedback loop (`runBrandMemoryFeedbackLoop`)**:
  - Automatic detection of dominant channels (e.g. TikTok outperforming LinkedIn by 80%).
  - Measurement of net profitability and hook effectiveness.
  - Atomic update of the editorial rules (`brand_profiles.editorial_rules`) to steer future campaign generations (brand memory, marketing plan and editorial calendar).

### 2.3 Express API routes (`server/src/routes/marketing-analytics.ts`)
- `POST /api/companies/:companyId/studio/analytics/metrics`: batch metric ingestion.
- `GET /api/companies/:companyId/studio/analytics/overview`: consolidated analytics view (filterable by period: 7, 30, 90 days).
- `POST /api/companies/:companyId/studio/analytics/feedback-loop`: triggers the AI learning loop.
- `GET /api/companies/:companyId/studio/analytics/insights`: history of generated recommendations.

### 2.4 User interface (`ui/src/components/MarketingAnalyticsPanel.tsx`)
- Real-time KPI cards (Reach, Clicks and Conversions, Average Engagement Rate, Profitability/ROI).
- Visual per-channel performance progress bar.
- Interactive `⚡ Activate AI Feedback Loop` button.
- Grid of strategic learnings with `✓ Integrated into Brand Memory` badges.
