---

## Requirements

Node.js 22 or later, pnpm, and Docker for the video worker. The server can use embedded PostgreSQL with no separate installation.

From the root of the SORAVYN repository:

```sh
pnpm install
pnpm dev
```

The interface and the API share http://localhost:3200. Do not expose the local_trusted mode to the Internet.

## Prepare a video production

```sh
pnpm video:image
DATABASE_URL=postgres://USER:PASSWORD@HOST:PORT/DATABASE pnpm video:worker
```

The server and the worker must share the same database and the same SORAVYN_VIDEO_ROOT directory. Use your own installation's settings, not production credentials copied from the examples.

In the dashboard: create a client, save its brand, create a campaign, then open Video Studio. Enter the scenes or load a draft generated by the configured local model. Start the render, then review and approve before delivery.

## Local CLI

```sh
pnpm soravyn --help
pnpm soravyn doctor
```

No public npm package or remote SORAVYN repository is assumed to be published. The documented commands run from this repository.

## Existing installation

New installations use ~/.soravyn. Older configurations and data are recognized without being moved or deleted. Compatibility details and the video commands are in doc/IDENTITY_MIGRATION.md and doc/VIDEO_WORKER.md at the root of the repository.
